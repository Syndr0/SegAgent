# Historical archive

[Project overview](../README.md) · [Current setup guide](getting-started.md)

**SegAgent Research v3 on `main` is the current application.** Its source lives
in [`segagent-research-v2/`](../segagent-research-v2/) because that directory
name is retained for historical path compatibility.

The [`segagent/`](../segagent/) directory preserves an earlier plugin-based
prototype for source history and research context. It is an archive, not an
alternative installation or a supported deployment target. Its APIs, settings,
and external plugin assumptions do not describe the current application.

The archived code remains available for inspection. Start from the
[current setup guide](getting-started.md) and
[current architecture](architecture.md) for the final implementation.
